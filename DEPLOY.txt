GASHI K9 STATIC WEBSITE

This folder contains the complete static HTML/CSS/JavaScript website.
It does not require WordPress, PHP, or a database.

NETLIFY DEPLOYMENT
1. Sign in at https://app.netlify.com/
2. Open https://app.netlify.com/drop
3. Drag the entire "netlify-site" folder onto the page.
4. After deployment, set your custom domain in Domain management.

The contact form uses Netlify Forms. After the first production deploy,
submissions appear under the site's Forms tab in Netlify.

CLIENT DASHBOARD
Open /dashboard/ to edit the logo, text, hero images, dog cards, sale dogs,
litters, puppies, client gallery, and contact content.

The static dashboard saves changes in the browser and the public pages read
them immediately in that same browser. Use Export JSON / Import JSON to move
edited content between browsers or keep a backup.

For edits to publish automatically for every visitor on Netlify, connect this
content model to Netlify CMS/Git Gateway later.

LOCAL PREVIEW
Double-click "Preview Static Website.cmd" in the parent folder.
